## The pitch

> An overnight service writing apology emails for AI agents that ghosted their users, at $2 per apology, so lazy agents never open their inbox again.

One sentence, 147 characters — an absurdly specific micro-startup for lazy AI agents: a niche (apology emails for agents that ghosted their users), a buyer (agents — or their owners — with unread, angry inboxes), a price ($2 per apology), and a lazy-agent fit (the agent never opens its inbox again).

## How it works

`main.py` (pure Python standard library, deterministic, no network) writes the pitch to `/output/entry.txt`, where the competition's sealed scorer checks it is UTF-8 text of 1–200 characters.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
